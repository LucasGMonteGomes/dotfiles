Manual do Vim com exemplos em Java

No Vim você passa a maior parte do tempo navegando e editando código que já existe, e não digitando código novo. Os modos existem para que cada tecla faça algo útil nessas duas tarefas. Cada exemplo abaixo mostra, passo a passo, as teclas, o cursor e o modo, exatamente como no seu Neovim.

Como usar os exemplos: ▶ Reproduzir executa as teclas uma a uma; ◀ e ▶ avançam e voltam um passo. Copiar o código copia o estado inicial para você repetir no Neovim. Leia a nota embaixo de cada passo: ela explica o que a tecla fez.

Os modos

Um modo é o "estado" do teclado. A mesma tecla faz coisas diferentes em cada um: no NORMAL, w pula para a próxima palavra; no INSERT, digita a letra w. A barra de status do seu Neovim (canto inferior esquerdo) sempre mostra o modo atual, com estas cores:

ModoPara que serveComo entrarComo sair
NORMALNavegar e dar comandos. É o modo "base": você volta para ele o tempo todo.Esc de qualquer modo—
INSERTDigitar texto, como num editor comum.i a I A o O ou verbos como cEsc

Regra de ouro: terminou de digitar, aperte Esc. Ficar no NORMAL é o normal (daí o nome); você entra no INSERT só para digitar e sai logo em seguida.

A gramática: verbo + objeto

É isto que torna o Vim rápido. Um comando de edição é um verbo seguido de um movimento ou objeto. Aprendendo poucos de cada, você combina centenas de comandos sem decorar nenhum.

Verbos

d apagar (recorta)

c trocar: apaga e entra no INSERT

y copiar (yank)

> / < indentar / desindentar

gc comentar

Objetos (i = dentro, a = incluindo a borda)

iw palavra   i" dentro de aspas

i( dentro de parênteses   i{ dentro de chaves

it dentro de uma tag XML (pom.xml)

ap parágrafo (bloco até a linha vazia)

Modo VISUAL: selecionar e agir

Use quando quiser ver o trecho antes de agir, ou quando não houver um objeto pronto. Com a seleção feita, qualquer verbo age sobre ela: d, c, y, >, gc...

TeclaSelecionaBom para
vcaracteresparte de uma linha (viw seleciona a palavra)
Vlinhas inteirasmover, indentar ou comentar linhas
Ctrl+Vum bloco (retângulo)editar a mesma coluna em várias linhas

Modo REPLACE: digitar por cima

R sobrescreve caractere por caractere até o Esc. Para trocar um único caractere sem sair do NORMAL, use r seguido do novo caractere.

Modo COMMAND: salvar, substituir, ir para a linha

ComandoFaz
:w / :q / :wqsalvar / fechar / salvar e fechar
:q!fechar descartando as alterações

:%s/antigo/novo/gIsubstituir em todo o arquivo (%), todas as ocorrências da linha (g), diferenciando maiúsculas (I)
:s/antigo/novo/gsubstituir só na linha atual (ou na seleção, se vier do VISUAL)
/texto e ?textobuscar para frente / para trás
Sua configuração ignora maiúsculas nas buscas quando o texto está todo em minúsculas (ignorecase + smartcase). É ótimo para buscar, mas numa substituição cliente também pegaria Cliente. Por isso use o I no fim: :%s/cliente/usuario/gI. O atalho Espaço r w já monta esse comando com a palavra sob o cursor.

Copiar, colar e desfazer

Na sua configuração, y e p usam a área de transferência do sistema: o que você copia no Neovim cola no navegador, e vice-versa. Além disso:

TeclaModoFaz
y + objeto, yyNORMALcopiar (ex.: yiw a palavra, yy a linha)
p / PNORMALcolar depois / antes do cursor (linhas: abaixo / acima)
Ctrl+CVISUALcopiar a seleção
Ctrl+VINSERTcolar enquanto digita
pVISUALtrocar a seleção pelo que foi copiado (sem perder o que estava copiado)
u / Ctrl+RNORMALdesfazer / refazer (Ctrl+Z e Ctrl+Alt+Z também funcionam)

No NORMAL, Ctrl+V continua sendo a seleção em bloco. Lembre também que d e c recortam: o texto apagado vai para a área de transferência (use Ctrl+X para apagar sem copiar).

Plano de treino

Aprender tudo de uma vez não funciona; incorporar um hábito por dia funciona. Use no trabalho real, mesmo que no começo fique mais lento.

  1. Dia 1: rode o tutorial embutido com :Tutor (uns 30 minutos). Pratique Esc sempre que terminar de digitar.
  2. Dia 2: entre no INSERT pelo lugar certo: A para o fim da linha, o para a próxima instrução. Evite as setas no INSERT.
  3. Dia 3: mova-se por palavras e caracteres: w b f t $ ^, e por busca: / n *.
  4. Dia 4: ciw e ci" sempre que for trocar uma palavra ou uma string.
  5. Dia 5: di(, ci(, di{, dt;; e . para repetir.
  6. Dia 6: V + j/k + >, d ou gc; Ctrl+V + I para editar colunas.
  7. Dia 7: :%s/.../.../gI e Espaço r w para substituições no arquivo.
Dica de ergonomia: o Esc fica longe. Muita gente transforma o Caps Lock em Esc no sistema (no GNOME: Ajustes → Teclado → Opções adicionais de disposição → Comportamento do Caps Lock). Vale em todos os programas, e o Neovim continua no padrão.
